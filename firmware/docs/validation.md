# 首版软件验证记录

## 已完成

- 使用工程自带的 `fetch_vendor.py` 获取固定的 HAL、Device 和 CMSIS Core，验证从空 vendor 目录构建。
- 使用 xPack GNU Arm Embedded GCC 14.2.1 交叉编译 STM32L476RG，项目源码启用 `-Wall -Wextra -Werror`，生成 ELF、HEX 与 Map。
- 默认配置和启用 USART2 日志的本地配置示例均通过编译。
- 默认构建应用 Flash 占用 25408 字节，命令表占用 8 字节，SRAM1 占用 7720 字节，含预留堆栈。不同编译器版本可能改变这些数值。
- TinyCC 0.9.27 执行 9 组 C 测试全部通过，包含八个独立提交断点的掉电恢复场景。
- Python unittest 的 5 项服务器测试全部通过，包含真实 localhost TCP 分片收发和数据库持久化检查。

## 尚未验证

没有连接真实 STM32、EC200U、SIM、电池或 GNSS。无法据软件测试认定真实网络已通、模块电源时序已匹配、ADC 电压已校准、传感器能可靠唤醒，或整板待机电流已达标。

真实样机的验证步骤见 bringup.md。硬件完成后，应补充板号、模块固件版本、供电曲线、串口记录、服务器记录和整板电流积分，再决定是否进入后续指令与定位功能开发。
